# Security Notes

CareLink Medical Center is a fictional environment created for educational and portfolio purposes.

The repository contains no real hospital infrastructure, credentials, patient information, production addresses, or sensitive organizational data.

The architecture demonstrates concepts including network segmentation, least privilege, IoMT isolation, firewalling, NAT/PAT, traffic filtering, and security validation.

This project should not be interpreted as a production healthcare network design, HIPAA compliance assessment, clinical safety architecture, or regulatory recommendation.
